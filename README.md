# Многопоточный расчёт — имитация параллельных вычислений

## Описание

Консольное приложение для имитации многопоточного расчёта с визуализацией прогресса каждого потока.

## Параметры

- `THREAD_COUNT` — количество потоков (по умолчанию: 4)
- `CALCULATION_LENGTH` — длина прогресс-бара (по умолчанию: 50)
- `SYMBOL_DELAY_MS` — задержка между символами прогресс-бара (по умолчанию: 100 мс)

## Требования

- Java 21+
- Maven 3.6+

## Сборка и запуск

```bash
# Сборка
mvn clean compile

# Запуск
mvn exec:java -Dexec.mainClass="org.example.Main"
```

## CI/CD

Проект использует GitHub Actions для автоматической сборки и тестирования.
