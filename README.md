# Система управления ролями и правами доступа (RBAC)

Этот проект представляет собой консольное приложение для управления пользователями, ролями и правами доступа с использованием модели RBAC (Role-Based Access Control).

## Структура проекта

Проект включает следующие основные компоненты:

### 1. Базовые структуры данных

#### User (record)
- `username` — уникальное имя пользователя (3-20 символов, только латинские буквы, цифры и подчеркивание)
- `fullName` — полное имя
- `email` — электронная почта

Методы:
- `validate(String username, String fullName, String email)` — валидирует и создает пользователя
- `format()` — возвращает форматированную строку с информацией о пользователе

#### Permission (record)
- `name` — название права (в верхнем регистре, без пробелов)
- `resource` — ресурс, к которому применяется право (в нижнем регистре)
- `description` — описание права

Методы:
- Канонический конструктор для валидации и нормализации полей
- `format()` — форматированный вывод
- `matches(String namePattern, String resourcePattern)` — поиск по шаблонам

#### Role (class)
- `id` — уникальный идентификатор роли (UUID)
- `name` — название роли
- `description` — описание роли
- `permissions` — набор прав доступа

Методы:
- `addPermission(Permission permission)`
- `removePermission(Permission permission)`
- `hasPermission(Permission permission)`
- `hasPermission(String permissionName, String resource)`
- `getPermissions()` — возвращает неизменяемую копию
- `format()` — форматированный вывод

#### AssignmentMetadata (record)
- `assignedBy` — кто назначил роль
- `assignedAt` — дата и время назначения
- `reason` — причина назначения (опционально)

Методы:
- `now(String assignedBy, String reason)` — создает с текущей датой/временем
- `format()` — форматированный вывод

### 2. Система назначений ролей

#### RoleAssignment (interface)
Интерфейс для назначения роли пользователю:
- `assignmentId()` — уникальный идентификатор
- `user()` — пользователь
- `role()` — роль
- `metadata()` — метаданные
- `isActive()` — активно ли назначение
- `assignmentType()` — тип назначения
- `summary()` — сводная информация

#### AbstractRoleAssignment (abstract class)
Абстрактный класс, реализующий интерфейс RoleAssignment:
- Общая реализация полей и методов
- Абстрактные методы `isActive()` и `assignmentType()`
- Метод `summary()` для форматированного вывода

#### PermanentAssignment (class)
Постоянное назначение:
- Всегда активно, пока не будет отозвано
- Тип: "PERMANENT"
- Поддерживает отзыв через `revoke()`

#### TemporaryAssignment (class)
Временное назначение:
- Активно до истечения срока действия
- Тип: "TEMPORARY"
- Поддерживает продление срока действия

## Функциональность приложения

Консольное приложение предоставляет следующие возможности:

1. **Управление пользователями**:
   - Создание, редактирование, удаление, просмотр
   - Валидация данных при создании

2. **Управление ролями**:
   - Создание, редактирование, удаление, просмотр
   - Добавление и удаление прав доступа

3. **Управление назначениями**:
   - Создание постоянных и временных назначений
   - Отзыв постоянных назначений
   - Продление временных назначений

4. **Поиск и фильтрация**:
   - Поиск пользователей, ролей и назначений
   - Фильтрация по различным критериям

5. **Статистика и отчеты**:
   - Статистика по пользователям, ролям и назначениям
   - Отчеты о правах доступа по ролям

6. **Сохранение и загрузка данных**:
   - Возможность сохранения и загрузки данных (в виде симуляции)

## Запуск приложения

Для запуска приложения выполните следующие шаги:

1. Убедитесь, что у вас установлена Java 14 или выше (необходимо для использования records)
2. Скомпилируйте проект:
   ```
   javac -d . src/main/java/*.java
   ```
3. Запустите приложение:
   ```
   java RBACConsoleApp
   ```

## Сборка с помощью Gradle

Проект также настроен для сборки с помощью Gradle:

1. Установите Gradle
2. Выполните команду для сборки:
   ```
   gradle build
   ```
3. Для запуска приложения:
   ```
   gradle run
   ```

- Абстрактные классы для общей реализации
- Валидация данных на уровне моделей
